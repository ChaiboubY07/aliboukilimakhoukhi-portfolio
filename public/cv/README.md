# CV — emplacement des fichiers

Déposez ici les deux fichiers du CV (noms exacts attendus par le site) :

| Fichier | Rôle |
| --- | --- |
| `cv.pdf` | Document PDF — lien « Télécharger (PDF) » de la section Contact |
| `cv.jpg` | Aperçu image du CV affiché sous « Mon parcours » (format portrait A4, idéalement ≤ 300 Ko pour la performance) |

Aucun redémarrage nécessaire en dev (`npm run dev`) : tant que `cv.jpg` est absent,
le site affiche un emplacement de remplacement élégant (monogramme AB).
